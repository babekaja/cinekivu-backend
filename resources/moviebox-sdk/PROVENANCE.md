# SDK Moviebox 0.2.4

Archive fournie : `moviebox-api-main (1).zip`. Les classes de recherche,
résolution de fichiers, sélection de qualité, sous-titres et téléchargement
par épisode ont été examinées avec les exemples et tests du SDK.

L'intégration des workflows est réécrite dans `cinekivu_downloads.py` et
utilise le moteur et le relais existants. Le paquet `moviebox-api` n'est pas
installé afin de préserver le module local homonyme `moviebox_api`.

Le fichier `LICENSE.md` reproduit la notice Unlicense livrée avec le SDK.
La comparaison détaillée se trouve dans `docs/ANALYSE_SDK_MOVIEBOX_024.md`.
